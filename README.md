# B.Tech Sabzi Wala PWA starter

This is an installable **prototype**, not a production ordering system.

## Included
- Responsive customer catalogue and basket
- Demo prices and delivery-fee calculation
- Home delivery / free pickup selection
- PWA manifest, service worker and iPhone home-screen icon
- No WhatsApp integration for now, as requested

## Publish using a phone
A simple route is to create a GitHub repository and upload these files, then import that repository into a static hosting service such as Vercel or Netlify. The deployed site must use HTTPS.

If uploading from an iPhone, extract the ZIP in the Files app first. GitHub's website may be awkward for uploading a complete folder from a phone; a computer is easier.

## Install on iPhone
1. Open the published HTTPS URL in Safari.
2. Tap Share.
3. Choose Add to Home Screen.
4. Enable Open as Web App if shown, then tap Add.

## Before real customer use
Connect a persistent database, secure owner login, live product/stock management, server-side order processing, payment provider, delivery-zone validation, backups, privacy policy and security controls. Replace sample prices with the shop's actual prices. Never treat the demo checkout as a real order.
